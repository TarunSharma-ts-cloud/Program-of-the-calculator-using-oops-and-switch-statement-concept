# Simple Calculator in C++

A simple command-line calculator application built using **C++** and **Object-Oriented Programming (OOP)** concepts. The program performs basic arithmetic operations through a menu-driven interface using a `switch` statement.

## Features

* Addition
* Subtraction
* Multiplication
* Division (with division-by-zero handling)
* Modulus (with zero-check validation)
* Menu-driven user interface
* Object-Oriented Programming using classes
* Simple and beginner-friendly code structure

## Technologies Used

* **Language:** C++
* **Concepts:**

  * Classes and Objects
  * Encapsulation
  * Member Functions
  * Switch Case
  * Conditional Statements

## Project Structure

```
calculator.cpp
```

## How It Works

1. The program prompts the user to enter two integers.
2. A menu of arithmetic operations is displayed.
3. The user selects an operation by entering the corresponding number.
4. The calculator performs the selected operation and displays the result.

## Operations Supported

| Option | Operation      |
| ------ | -------------- |
| 1      | Addition       |
| 2      | Subtraction    |
| 3      | Multiplication |
| 4      | Division       |
| 5      | Modulus        |

## Error Handling

* Prevents division by zero.
* Prevents modulus by zero.
* Displays an error message for invalid menu selections.
